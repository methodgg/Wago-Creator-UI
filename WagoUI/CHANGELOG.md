# 2.0.0-alpha1 (2026-10-28)

Alpha test of the new WagoUI. The Creator is now part of WagoUI, and UI Packs use a new format built around variations.

- Merge WagoUI Creator into WagoUI: use /wago to install UI Packs and /wagoc to create them
- Replace fixed resolutions with variations: named profile sets that can each target several resolutions
- Convert UI Packs from the previous creator automatically, keeping install history
- New Full Install flow for first-time users and a reworked Individual Profiles view
- Bring back the Cooldown Manager and WeakAuras managers in the creator
- Block saving a UI Pack with profiles that can't be saved, and warn about profile names players already have
- Add a guided tour for first-time UI Pack creators
- Show a banner when WagoUI_Storage is disabled, with a button to enable it and reload
- Replace Details! Framework with WagoUI's own controls
- Remove the NaowhQOL and ElvUI Style Filters integrations
- Update interface versions for the latest WoW clients
